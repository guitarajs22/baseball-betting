How to Import Historical Closing-Line Odds (Free)

We use the ArnavSaraogi mlb-odds-scraper dataset — free, covers 2021–2025, includes moneyline + run line + totals from DraftKings, FanDuel, BetMGM, Caesars, Bet365, BetRivers.

  1. Go to github.com/ArnavSaraogi/mlb-odds-scraper/releases
  2. Download the latest release asset — look for a file called mlb_odds.json or similar (~76 MB).
  3. Save it anywhere on your Mac — for example your Downloads folder.
  4. Open Terminal and run (replacing the path with where you saved the file): 
    cd "/Users/{{ username or 'andrewsilva' }}/App Building/baseball-betting"
source venv/bin/activate
python import_historical_odds.py --file ~/Downloads/mlb_odds.json --year 2024
  5. Wait a minute for it to finish, then reload this page. The green counter above will update.
Tip: Add --year 2024 to only load 2024 data (much faster). You can always re-run with --year 2023 etc. later to add more seasons. The script is safe to run multiple times — duplicates are automatically skipped.
How the backtest works: Fetches real historical game scores from the MLB API, runs 10,000 Monte Carlo simulations per game using your current player stats, then checks whether a bet at the actual closing line (when available) would have been profitable. The backtest covers moneyline, totals, and run line bets — totals and run line are only evaluated when real historical prices are available.
